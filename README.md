# Ккал.Дневник — трекер калорий

Веб-приложение для учёта питания: анкета с расчётом суточной нормы, календарь приёмов пищи, большая база блюд и синхронизация данных через Supabase.

**Разработала: Анна Аришина (annarishvibe), 2026.**

## Возможности

- Регистрация и вход через Supabase Auth (email + пароль), восстановление пароля.
- Анкета: пол, возраст, рост, вес, уровень активности, цель и количество приёмов пищи (2–8).
- Расчёт суточной нормы по формуле Миффлина — Сан Жеора с поправкой на активность и цель; расчёт БЖУ и калорий на один приём.
- Календарь с отметками дней, в которые есть записи; выбор любой даты.
- Дневник по приёмам пищи: добавление блюда из базы, вес порции в граммах, автоматический пересчёт КБЖУ, удаление записей, копирование предыдущего дня.
- База блюд: 232 позиции «из коробки» (овощи, фрукты, белки, крупы, молочное, орехи, напитки, сладости, готовые блюда и др.) + пользовательские блюда, сохраняемые в Supabase.
- Поиск по базе, фильтр по категориям.
- Настройки: редактирование анкеты, ручная корректировка нормы, темы (светлая / тёмная / системная), смена пароля, экспорт дневника в CSV.
- Данные пользователя защищены политиками RLS: доступ к своим записям имеет только их владелец.

## Быстрый старт

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/annarishvibe/calorie-tracker.git
   cd calorie-tracker
   ```

2. Создайте виртуальное окружение и установите зависимости:

   ```bash
   python -m venv .venv
   # Windows: .venv\Scripts\activate
   # macOS/Linux: source .venv/bin/activate
   pip install -r requirements.txt
   ```

3. Скопируйте `.env.example` в `.env` и укажите URL проекта Supabase и **anon**-ключ:

   ```bash
   cp .env.example .env
   ```

4. В Supabase SQL Editor выполните `supabase/migrations/0001_init.sql`, затем `supabase/seed_foods.sql` (можно сгенерировать заново: `python scripts/seed_supabase.py`).
5. В Supabase → Authentication → Providers включите Email и при необходимости отключите подтверждение почты для локальной разработки.
6. Запустите приложение:

   ```bash
   python app.py
   ```

   Откройте http://localhost:5000.

### Переменные окружения

| Переменная | Назначение |
| --- | --- |
| `SUPABASE_URL` | URL проекта Supabase (`https://xxx.supabase.co`) |
| `SUPABASE_ANON_KEY` | Публичный anon-ключ (безопасен для браузера) |
| `SECRET_KEY` | Секрет Flask для сессий |
| `PORT` | Порт сервера, по умолчанию 5000 |

**Не помещайте service_role-ключ в браузер или в `.env.example`.** Все операции с данными выполняются из браузера с anon-ключом, а доступ разграничивается политиками RLS.

## Как считается норма

1. Базальный метаболизм (Миффлин — Сан Жеор):
   - мужчины: `10 × вес + 6,25 × рост − 5 × возраст + 5`;
   - женщины: `10 × вес + 6,25 × рост − 5 × возраст − 161`.
2. Умножается на коэффициент активности: 1,2 / 1,375 / 1,55 / 1,725 / 1,9.
3. Цель: похудение −500 ккал, поддержание 0, набор +300 ккал.
4. Белок: 1,6 г/кг (похудение), 1,4 г/кг (поддержание), 1,8 г/кг (набор).
5. Жиры: 25 % от калорийности / 9; углеводы: остаток / 4.
6. Норма делится на число приёмов пищи из анкеты — это ориентир для каждого приёма.

Расчёт дублируется на клиенте (мгновенный предпросмотр в анкете) и на сервере (`POST /api/nutrition/calculate`).
